# 🐍 100 Days of Python

Welcome to my **100 Days of Python** journey!

This repository documents my progress through **Dr. Angela Yu's 100 Days of Code: The Complete Python Pro Bootcamp**. My goal is not just to finish the course, but to become a software engineer by building a strong foundation in Python, problem-solving, and programming fundamentals.

Throughout this journey, I will upload all of my daily projects, coding exercises, and challenges. This repository will serve as both a learning journal and a record of my growth as a programmer.

## 🎯 Goals

- Learn Python from the ground up.
- Develop strong problem-solving skills.
- Understand programming concepts instead of memorizing syntax.
- Build clean, readable, and maintainable code.
- Create a complete portfolio of projects.
- Prepare for a career in Software Engineering and later specialize in AI/ML.
